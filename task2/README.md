# 双人炸金花实时联机游戏

这是一个用 Python 实现的浏览器实时联机小游戏。后端使用 `aiohttp` 同时提供网页和 WebSocket 服务，前端是单文件 `index.html`。

## 文件说明

- `server.py`：Python 服务端，包含房间管理、WebSocket 同步、游戏状态机、下注规则、牌型比较和结算逻辑。
- `index.html`：浏览器客户端，包含页面、样式和前端交互逻辑。
- `requirements.txt`：Python 依赖。
- `prompt.txt`：原始需求说明。

> 目录中如果存在 `J`、`K`、`Q`、`10`、`9`、`2` 等无扩展名空文件，它们不是游戏代码的一部分，当前实现不会读取或依赖这些文件。

## 运行方式

```bash
cd /Users/admin/work/temp/task2
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python server.py
```

浏览器打开：

```text
http://127.0.0.1:8000
```

用两个浏览器标签页或两个浏览器窗口即可模拟两名玩家联机。

如果提示 `127.0.0.1:8000` 端口已被占用，可以关闭占用该端口的程序，或修改 `server.py` 最后一行中的端口号。

## 游戏流程

1. 玩家 A 输入昵称并创建房间。
2. 玩家 B 输入昵称和房间号加入房间。
3. 双方都点击准备后自动开始。
4. 每人发 3 张牌，自己可以直接看到自己的牌。
5. 每局双方各下 1 个底注。
6. 双方轮流行动，可以选择：
   - 跟注
   - 加注
   - 弃牌
   - 比牌
7. 局结束后，双方都点击“再来一局”才会开始下一局。
8. 游戏未开始时可以退出房间。

## 规则说明

### 初始筹码

每名玩家初始有 100 个筹码。

### 底注

每局开始时，两名玩家各放入 1 个筹码作为底注。

### 行动

每次轮到自己时可以选择：

- **跟注**：放入当前注额。
- **加注**：提高当前注额，最高只能加到 5。
- **弃牌**：放弃本局，对方赢得奖池。
- **比牌**：双方亮牌，牌大者赢得奖池。

### 比牌限制

双方都至少行动过一次后，才允许比牌。

例如：

1. 甲跟注
2. 乙跟注
3. 此后任意一方轮到自己时可以比牌

### 回合上限

最多 6 轮，也就是最多 12 次行动。达到上限后如果还没人弃牌或比牌，系统会自动摊牌。

### 平局

- 主动比牌时，如果双方牌完全一样，主动比牌的人输。
- 自动摊牌时，如果双方牌完全一样，奖池平分。

## 牌型大小

从大到小：

1. 豹子：三张点数一样
2. 同花顺：同花色顺子
3. 同花：三张同花色
4. 顺子：三张连续
5. 对子：两张点数一样
6. 散牌：普通高牌

点数大小：

```text
A > K > Q > J > 10 > 9 > ... > 2
```

顺子特殊规则：

- `A K Q` 是最大顺子。
- `A 2 3` 是最小顺子。

## 验证建议

可以用两个浏览器标签页测试：

1. A 创建房间，B 加入房间。
2. 双方准备后检查是否发牌、奖池是否为 2。
3. 发牌后立即点“比牌”，应提示双方至少各行动一次后才能比牌。
4. 双方各行动一次后再比牌，应正常亮牌结算。
5. 测试加注最高只能到 5。
6. 测试弃牌后对方直接获胜。
7. 测试双方都点击“再来一局”后才开始新局。
